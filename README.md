# AmakanoPet

A lightweight desktop pet built with Python 3.10+ and PySide6.

## Run

```powershell
python -m pip install -r requirements.txt
python main.py
```

## Controls

- Drag the window with the left mouse button.
- Hold `Ctrl` and use the mouse wheel to resize it.
- Right-click the window or tray icon for visibility and exit controls.
- Press `Esc` to hide the window to the system tray.
